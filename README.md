# 📚 MY ENGINEERING PHILOSOPHY

### 01 · Build useful things

A project does not need to be huge to be valuable.

### 02 · Understand the product

Code is implementation. The product problem comes first.

### 03 · Keep the architecture intentional

Small applications should still have clear boundaries.

### 04 · Document decisions

Future-you is another developer who deserves context.

### 05 · Validate before declaring victory

A build passing is not the same as a product being ready.

### 06 · Use AI deliberately

AI accelerates exploration and implementation, but human judgment owns the result.

### 07 · Keep experimenting

Small experiments are part of becoming a better engineer.
